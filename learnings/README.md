# learnings/ — teachable patterns

Plain `.md` files loaded **additively** into context (not first-wins).
Capture *how to think*, not session state.

| File | Topic |
|------|-------|
| `01-teaching-mode.md` | Answer ML "what/why" questions like a teacher |

## When to add a learning

- A interaction pattern worked well and should repeat
- A hardware or algorithm insight generalizes beyond one project
- No usernames, home paths, or one-off cron IDs

Move project-specific notes to `$PROJECT_ROOT/.hermes/learnings/`.
